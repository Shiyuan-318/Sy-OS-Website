# Sy OS 产品官网 - 产品需求文档 (PRD)

## 1. 产品概述
Sy OS 是一个面向多终端的操作系统产品系列官网，展示 Sy OS 全系产品矩阵，包括桌面端、平板端、精简版、开源版、下一代版本、车载版和视觉版。网站采用深色风格设计，融合 Pinterest 瀑布流式内容展示与鸿蒙 7 的毛玻璃/圆角美学，打造沉浸式产品体验。

- 目标用户：Sy OS 潜在用户、技术爱好者、开发者社区
- 核心价值：通过精致的视觉体验传递产品品质感，清晰展示各产品线特色

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色背景 (#0a0a0f ~ #12121a)，搭配品牌蓝 (#3b82f6) 和紫 (#8b5cf6) 渐变作为强调色
- **辅助色**：毛玻璃白 (rgba(255,255,255,0.08))，卡片悬浮高亮边框
- **按钮风格**：圆角胶囊按钮，渐变背景，悬浮发光效果
- **字体**：标题使用 Outfit（几何感现代字体），正文使用 Noto Sans SC（中文优化）
- **布局风格**：Pinterest 式瀑布流卡片 + 鸿蒙7 式圆角毛玻璃面板
- **图标风格**：线性图标，2px 描边，圆角端点
- **导航栏**：悬浮圆角设计，毛玻璃背景，居中布局

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | Hero 区域 | 全屏渐变背景、动态光效、大标题+副标题、向下滚动指示 |
| 首页 | 产品矩阵 | 圆角卡片网格、悬浮放大+发光、产品图标+名称+简介 |
| 首页 | 特色亮点 | 左右交替布局、滚动渐入动画、图标+标题+描述 |
| 产品页 | 产品 Hero | 渐变背景、产品名+标语、装饰性几何图形 |
| 产品页 | 功能特性 | 3列网格、毛玻璃卡片、图标+标题+描述 |
| 产品页 | 产品亮点 | 大图+文字交替、视差滚动效果 |
| 产品页 | CTA 区域 | 居中大按钮、渐变背景、脉冲动画 |
| 活动页 | 活动列表 | 瀑布流卡片、日期标签、占位内容 |
| 全局 | 导航栏 | 固定顶部悬浮、圆角容器、毛玻璃背景、Logo+菜单项 |
| 全局 | 页脚 | 深色背景、链接列表、版权信息 |

### 4.3 响应式设计
- 桌面优先设计（Desktop-first）
- 平板端：卡片网格从3列调整为2列
- 移动端：单列布局，导航栏折叠为汉堡菜单

### 4.4 动效设计
- 页面加载：元素依次渐入（stagger animation）
- 滚动触发：IntersectionObserver 驱动的渐入效果
- 卡片悬浮：轻微上浮 + 边框发光
- 导航栏：滚动时背景模糊度增强
- 按钮：悬浮时发光脉冲
