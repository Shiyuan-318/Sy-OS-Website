## 1. 产品概述
Sy OS 官方网站重写项目——将现有的多页面静态 HTML 网站升级为现代化、视觉冲击力强的 React 单页应用，展示 Sy OS 系列操作系统产品线。
- 目标：打造高端科技品牌官网，提升视觉品质与交互体验，突出产品矩阵的丰富性与创新性
- 目标用户：对 Sy OS 系列操作系统感兴趣的科技爱好者、开发者和普通用户

## 2. 核心功能

### 2.1 功能模块
1. **首页**：沉浸式 Hero 轮播、产品矩阵展示、核心特性、在线体验入口
2. **产品详情页**：各产品独立展示页，含产品图、功能描述、特色亮点

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | Hero 轮播区 | 全屏沉浸式轮播，展示 Sy OS / NEXT / Vision 三大核心产品，自动切换+手动控制 |
| 首页 | 产品矩阵 | 7 款产品卡片网格展示，含产品图、名称、简介、了解更多链接，NEXT 标注"全新发布" |
| 首页 | 核心特性 | 4 个特性卡片：全场景跨平台、开放生态、产品覆盖面广、极简设计 |
| 首页 | 在线体验 | 5 个在线体验入口列表，链接到外部体验平台 |
| 首页 | 页脚 | 品牌信息、快捷链接、版权声明 |
| 产品详情页 | 产品展示 | 产品大图、标题、描述、功能详情 |
| 产品详情页 | 页脚 | 品牌信息与版权 |

## 3. 核心流程
用户访问首页 → 浏览 Hero 轮播了解核心产品 → 下滑查看产品矩阵 → 点击产品卡片进入详情页 → 或直接进入在线体验

## 4. 用户界面设计

### 4.1 设计风格
- **风格方向**：暗黑科技感 + 毛玻璃质感，参考高端科技品牌官网（如 Apple、Nothing）
- **主色调**：深邃黑 (#0a0a0a) 为底，搭配冷调蓝紫渐变 (#6366f1 → #8b5cf6) 作为强调色
- **辅助色**：银灰 (#a1a1aa)、暗灰 (#27272a)、纯白 (#fafafa)
- **字体**：展示字体使用 Outfit（几何感、现代科技感），正文使用 DM Sans（清晰易读）
- **按钮风格**：圆角胶囊按钮，毛玻璃背景 + 渐变边框
- **布局风格**：全宽沉浸式布局，大量留白，非对称构图打破常规
- **动效**：滚动触发渐入动画、卡片悬浮光效、轮播平滑过渡、鼠标跟踪光晕

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页 | Hero 轮播区 | 全屏暗色背景、渐变光晕装饰、产品大图、底部指示器、左右箭头控制 |
| 首页 | 产品矩阵 | 暗色卡片、悬浮发光边框、产品图、名称、描述、箭头链接 |
| 首页 | 核心特性 | 网格布局、图标 + 标题 + 描述、悬浮微动效 |
| 首页 | 在线体验 | 列表式卡片、悬浮滑入动效、箭头指示 |
| 首页 | 页脚 | 暗色背景、毛玻璃面板、品牌 Logo、链接 |
| 产品详情页 | 产品展示 | 大幅产品图、渐变背景、标题动画入场 |

### 4.3 响应式设计
- 桌面优先设计，适配 1440px / 1024px / 768px / 375px 断点
- 移动端：汉堡菜单、单列布局、触控优化
- 平板：双列产品网格、简化动效

### 4.4 动效策略
- 页面加载：元素交错渐入（staggered fade-in）
- 滚动触发：IntersectionObserver 驱动的渐入动画
- 卡片悬浮：边框发光 + 微上浮 + 阴影加深
- 轮播：平滑淡入淡出 + 背景渐变过渡
- 鼠标跟踪：Hero 区域光晕跟随效果
